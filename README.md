`main.py` writes one funny sign line for the door of a haunted server room
(1–120 characters) to `/output/entry.txt`.

The sign:

> Do not unplug Rack 3. The ghost inside is the only one who remembers the root password.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
